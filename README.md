# موقع طالب علم — تعليمات النشر

الموقع عبارة عن ملف واحد `index.html` (HTML + CSS + JS) مفيهوش أي خطوة بناء (build) —
تقدر ترفعه زي ما هو على أي استضافة مجانية.

## قبل الرفع
1. غيّر رابط زرار "حمّل النسخة التجريبية (APK)" — دور في الملف على السطر اللي فيه:
   `<!-- ضع رابط تحميل ملف الـ APK هنا -->` وحط الرابط في `href="#"` اللي جنبه.
2. حط روابط إنستجرام وفيسبوك الحقيقية بدل `#` — دور على تعليق
   `<!-- ضع رابط إنستجرام هنا -->` و `<!-- ضع رابط فيسبوك هنا -->`.
3. استبدل إطارات الصور المتقطعة (اللي مكتوب فيها "هتتحط هنا") بالصور الحقيقية بتاعتك.
4. **مهم:** ارفع الملفات دي كلها مع بعض في نفس المجلد (مش `index.html` بس):
   `favicon-32.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `og-image.png`
   ومجلد `assets/` بالكامل (فيه `app-icon.png` — أيقونة التطبيق الحقيقية المستخدمة جوه الصفحة نفسها)
   — دول أيقونة المتصفح وصورة المعاينة اللي بتظهر لما حد يبعت لينك الموقع في واتساب/تليجرام.

## أسهل طريقة تنشره بيها (Vercel) — زي مشاريعك السابقة
1. اعمل ريبو جديد على GitHub وارفع فيه `index.html` بس.
2. ادخل [vercel.com](https://vercel.com) وسجل دخول بحساب GitHub.
3. Add New Project → اختار الريبو → Deploy. خلاص، هياخدلك رابط زي
   `talib-ilm.vercel.app` تقدر بعدين تربط عليه دومين مخصص لو حبيت.

## أو GitHub Pages (أبسط وأسرع)
1. في نفس الريبو: Settings → Pages → اختار الفرع `main` والمجلد `/root`.
2. هيديك رابط زي `username.github.io/repo-name`.

- الخطوط بتتحمل من Google Fonts، فمحتاج اتصال إنترنت عادي وقت الفتح بس.
