# طالب علم — الموقع الترويجي

الموقع الرسمي لتطبيق **طالب علم**، تطبيق مخصص لطلاب الثانوية العامة والبكالوريا المصرية لتنظيم مذاكرتهم وجدولهم ومواعيدهم حسب نظامهم وصفهم وشعبتهم.

## عن الموقع

موقع ترويجي بصفحة واحدة (Single Page) بيعرض:
- فكرة التطبيق ومميزاته (جدول مذاكرة، مؤقت بومودورو، الركن الديني، الإنجازات، منتدى الطلاب)
- سكرين شوتات حقيقية من التطبيق
- توضيح واضح لمكان تخزين بيانات المستخدم (محليًا على الجهاز مقابل ما يحتاج اتصال سيرفر)
- زر تحميل نسخة الـ APK المباشرة (قبل النشر الرسمي على Google Play)
- قسم دعم لتمويل نشر التطبيق على المتجر

## البنية التقنية

الموقع بالكامل ملف واحد `index.html` (HTML + CSS + JS مدمجين)، من غير أي build tools أو dependencies — بيترفع زي ما هو مباشرة.

### الملفات المطلوبة عند الرفع
لازم ترفع كل الملفات دي مع بعض، مش `index.html` بس:

```
index.html
favicon-32.png
icon-192.png
icon-512.png
apple-touch-icon.png
og-image.png
assets/
  app-icon.png
  play-protect-warning.webp
  screenshots/
```

### تحديث رابط تحميل الـ APK
الرابط متمركز في مكان واحد بس داخل `<script>` في `index.html`:

```js
const APK_URL = "...";
```

تغيير القيمة دي بيحدّث كل أزرار التحميل في الموقع تلقائيًا (الهيدر، منتصف الصفحة، وقسم الـ CTA النهائي).

## النشر

الموقع static بالكامل، يشتغل على أي استضافة ملفات ثابتة (GitHub Pages مثلًا):

1. من إعدادات الريبو: **Settings → Pages**
2. اختار الفرع `main` والمجلد `/ (root)`
3. Save — هياخد شوية دقايق ويديك رابط زي `username.github.io/repo-name`
